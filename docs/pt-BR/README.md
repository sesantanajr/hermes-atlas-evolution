# Documentação do Atlas Evolution

[English](../en-US/README.md) · **Português (Brasil)** · [Voltar ao projeto](../../README.pt-BR.md)

O Atlas Evolution é um plugin do Hermes Agent que aprende com os erros do agente, mede se o agente está melhorando, mantém todos os perfis de um Hermes saudáveis e se repara sozinho. Estas páginas explicam como usá-lo e como ele funciona.

## Comece aqui

| Página | Leia quando |
|---|---|
| [Primeiros passos](getting-started.md) | Você está instalando, ou quer saber o que ele faz na primeira hora e como deixá-lo do seu jeito. |
| [Solução de problemas](troubleshooting.md) | Algo não parece certo: o gateway não sobe, um perfil está fixado, um comando é recusado, um número parece estranho. |
| [Atualização](upgrading.md) | Você quer a versão mais nova em todos os perfis. |
