# Atlas Evolution documentation

**English** · [Português (Brasil)](../pt-BR/README.md) · [Back to the project](../../README.md)

Atlas Evolution is a Hermes Agent plugin that learns from the agent's mistakes, measures whether the agent is getting better, keeps every profile of a Hermes healthy and repairs itself. These pages explain how to use it and how it works.

## Start here

| Page | Read it when |
|---|---|
| [Getting started](getting-started.md) | You are installing it, or want to know what it does in its first hour and how to make it yours. |
| [Troubleshooting](troubleshooting.md) | Something does not look right: the gateway does not start, a profile is pinned, a command is refused, a number looks off. |
| [Updating](upgrading.md) | You want the latest version in every profile. |
